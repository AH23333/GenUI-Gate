## 渠道一：A2UI GitHub Discussions（Show and tell / Show & Tell 板块）

**标题：GenUI Gate — a deterministic "linter + lighthouse" for A2UI specs (open source, Apache-2.0)**

Hey folks 👋

We've been following A2UI since the early spec drafts, and one thing kept bothering us: agents can now emit UI declarations that hosts render directly — but nothing in that pipeline checks the *structure*. No linter, no budget, no gate before render.

So we built **GenUI Gate** — an open-source, protocol-agnostic (A2UI-first) quality gate for agent-generated UI. Apache-2.0, zero telemetry, no accounts.

What the M0 CLI (`genui-audit`) does today:

- **Parses & adapts** the official A2UI wire formats (v0.9.x and v1.0; single messages, arrays, JSONL, example wrappers) into a normalized IR
- **Enforces hard limits** — tree depth 32, 2000 nodes, 64 children, 16KB props — fail-closed against DoS-shaped specs, with an explainable trace per violation (rule id + node path + reason)
- **Hashes deterministically** — canonical JSON (JCS subset) + sha256, so the same spec produces the same IR hash on every platform
- **Reports an accessibility baseline** per surface (label / description / live-region / hidden coverage) — real a11y policy rules land in M1

The whole official fixture corpus (53 examples across v0.9.1 and v1.0, including the eval payloads) is embedded as a golden test set — every fixture parses, adapts, and audits with byte-identical digests on ubuntu/windows × Node 20/22 in CI.

Sample output — a passing spec:

```
Surface "gallery-invitation-builder" (https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json)
  Components: 20, nodes: 20, max depth: 7
  IR hash: 2efbebdc3dd0976206b3ba1b431c5bf1c95a932c44b57ec1f99e2a87e1fb4c85
  Verdict: pass
  A11y baseline: 20 nodes, 0 with accessibility metadata, 0 with label, 0 with description, 0 live region, 0 hidden
  Rule violations: none
```

...and a 33-deep card stack getting blocked (`depth 33 exceeds limit 32`, exit code 2).

Determinism is the core design constraint: the core packages are zero-dependency, pure, and synchronous — no `Date.now()`, no `Math.random()`, no locale-sensitive comparisons. Bench on the A6 budget tree (500 nodes / depth 12): p99 0.81ms against a 5ms budget.

Roadmap: M1 brings the a11y rule pack (heading structure, landmarks, focus order), session + runtime gating, pending-inert and spec rollback; M2 adds framework integration and a public "GenUI accessibility field survey" built with this CLI.
